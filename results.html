📊 System Overview

This system uses fuzzy logic to handle uncertainty in student performance evaluation. Unlike traditional binary systems, it provides nuanced predictions based on multiple attributes.

  • Input Variables: Attendance, Assignments, Midterms, Participation
  • Output Variable: Performance Level (5 categories)
  • Inference Method: Mamdani Fuzzy Inference
  • Dataset: Synthetic 50-student dataset
